# Автопрайм — веб-сайт автосалона

Учебный MVP по курсовой работе «Разработка веб-сайта для магазина автомобилей „Автопрайм“».

## Возможности
- Каталог автомобилей, поиск, фильтры и сортировка.
- Регистрация, авторизация и роли пользователей.
- Личный кабинет, избранное и история заявок.
- Заявки на покупку, тест-драйв и Trade-in.
- Предварительный кредитный калькулятор.
- Панель администратора: добавление автомобилей, архивирование, обработка заявок и базовая статистика.
- SQLite для локального запуска; структура таблиц соответствует основным сущностям из курсовой.

## Запуск в Windows
1. Установите Python 3.10 или новее.
2. Распакуйте архив и откройте папку `avtoprime` в командной строке.
3. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустите сайт:
   ```bash
   python app.py
   ```
6. Откройте в браузере: http://127.0.0.1:5000

## Важное замечание для защиты
В текущем учебном прототипе используется SQLite, чтобы проект запускался локально без установки отдельного сервера БД. В пояснительной записке целевой СУБД указана MySQL; для полного соответствия промышленному варианту нужно заменить слой подключения к SQLite на MySQL и настроить сервер БД.
Кредитный расчёт реализован отдельным серверным модулем предварительной оценки. Для реальной интеграции с API банка-партнёра потребуется адрес API, документация и ключ доступа; без них нельзя достоверно подключить банковский сервис. В интерфейсе явно указано, что результат предварительный.
